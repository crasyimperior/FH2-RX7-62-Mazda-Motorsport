Mazda RX-7 Mazda Motorsport #62 (1991 IMSA GTO) - Forza Horizon 2 PC
Ported from Forza Motorsport 6. Version 1.0 - car Id 19921.

REQUIREMENTS
- Forza Horizon 2 on PC with Azimuth 1.0.4
- Extra Options 0.4.4 or newer (it loads the "mods" folder)

INSTALL
1. Close the game.
2. Extract this zip into your Azimuth folder (the one that contains azimuth.exe).
   You get: mods\MAZ_62_RX7_91 Mazda Motorsport
3. Start the game. The car is sold at the Autoshow, under Mazda, for 650,000 CR.

UNINSTALL
Delete the folder mods\MAZ_62_RX7_91 Mazda Motorsport.

NOTES
- The mod ships its own MasterBank.strings.bank (needed for the car's own engine sound).
  Another mod that replaces the same file will conflict with it.
- Night headlights were added (the FM6 car only had the empty covers): they light up with
  the game's headlights.
